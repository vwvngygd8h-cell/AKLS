# AKLS V9.2

Hotfix gegen zu viele gelbe Kennzeichenboxen.

## Geändert
- Gelb erscheint erst, wenn dieselbe Region in mindestens 2 Detektorläufen bestätigt wurde.
- Maximal 2 sichtbare Kennzeichenkandidaten gleichzeitig.
- Strengere Kennzeichen-Geometrie.
- Engere zulässige Seitenverhältnisse.
- Höhere Anforderungen an Helligkeit, Kanten und dunklen Zeichenanteil.
- Falsche Kandidaten verschwinden schneller.
- OCR wird nur noch auf bestätigte Kandidaten angewendet.
- Alle V9.1-Kamera- und Multi-Frame-Funktionen bleiben erhalten.
