# AKLS V9.1

Hotfix für V9.

## Behoben
- iPhone/iOS: Scan konnte laufen, während der Kamera-Platzhalter das Livebild verdeckte.
- Video wird nun explizit sichtbar gestapelt.
- Platzhalter wird beim Start sowohl per `hidden` als auch per CSS/JS entfernt.
- AKLS wartet auf `loadedmetadata`, bevor die Scanansicht aktiv wird.
- `playsinline`, `webkit-playsinline`, `autoplay` und sichtbare Video-Ebene für Safari/PWA abgesichert.
- Service-Worker-Cache auf V9.1 erhöht.

Alle V9-Erkennungsfunktionen bleiben erhalten.
